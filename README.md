# Matter Factory

Matter Factory is a mod for multi-dimensional resource gathering, factory building, and resource processing.

This mod is currently in development. Expect bugs, incomplete features, and missing documentation.

---
## Development Resources
This mod is built specifically for NeoForged 26.2.

Project Lombok is used for generating boilerplate code and is required.

## Want to contribute?
We recommend you use IntelliJ IDEA for development. The Community Edition is free and will be more than enough.
Look at the [contribution guide](docs/CONTRIBUTING.md) for more information. Code style guidelines can be found in the [code style guide](docs/CODE_STYLE.md).

### How to implement a new features
Please read the [contribution guide](docs/CONTRIBUTING.md) for more information. We require an RFC process for all new features.
Please do not implement features that are not in the RFC process, as we may not accept them, which will result in a waste
of your time. 

### Texturing
We will always accept texture recommendations, especially as not all of us are that good at it. Please create a pull request
with the textures and we will review it. 

### Translations
We will always accept translation contributions via Crowdin.
